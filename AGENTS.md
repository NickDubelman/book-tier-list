This project is for organizing books I've read and how I have rated them. The list will be presented in a style similar to a tier list.

- There will be rows for different rankings. Unlike a regular tier list, we will use numbers instead of letters. The numbers will go from 5 to 0.5 in increments of 0.5. 5 will have a green color associated with it and 0.5 will have a red (the colors in between will gradually transition, like a gradient).
- We will use AstroJS and TailwindCSS
- The UI should look good on mobile
- The tier list and book rankings will be defined as a YAML file
- Each book will have an image associated with it. Hovering (or touch, on mobile) should show a tooltip that gives the books title and author
